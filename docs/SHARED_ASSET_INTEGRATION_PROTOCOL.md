# Shared asset integration

Use the existing shared art repository and [platform contract](SHARED_ASSET_PLATFORM.md). Do not duplicate its library in this game repository.

1. Identify the game role and approved perspective before selecting art.
2. Check source provenance and redistribution permission.
3. For characters, inspect coherent directional action frames, real alpha, stable canvas, ground pivot, scale and equipment handedness.
4. Preserve native pixels and colors when packing sheets. Display scale is separate.
5. Integrate the selected sheet and its frame metadata into the existing presentation system.
6. Inspect actual movement and combat on the island; a still image or passing import check is not animation acceptance.
7. Delete superseded files and update every consumer. Commit the unified result on the existing repository history.

Gameplay positions, collision, allegiance, damage and action timing remain owned by the simulation. Artwork only presents them.
