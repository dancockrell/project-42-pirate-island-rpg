# Tabletop Warm Wood Furnishings — local draft

This is a neutral, authored shared resource pack for readable interiors. Its
eight source meshes come from the CC0 Kenney Furniture Kit; the local authored
material profile deliberately makes them matte warm wood at tabletop scale.

It is neither DragonRealms furniture nor Project 42 furniture. Each game may
place, recolor, or reject it after scene review. The full lineage and searchable
metadata are in `resource-pack.json`.
