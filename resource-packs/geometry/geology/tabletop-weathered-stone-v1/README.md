# Tabletop Weathered Stone — local draft

This reusable resource pack is organized by **geometry / geology / authoring
lineage**, not by a consuming game. It contains ten CC0 Kenney Nature Kit rocks
and one locally authored Godot `StandardMaterial3D` profile that makes the
family read as matte, blue-grey, weathered tabletop stone.

To test a member in Godot, instantiate a model from `models/`, then apply
`materials/tabletop_weathered_stone.tres` as the mesh material override. This
material profile is deliberately simple: it should improve a toy-like tabletop
scene without pretending to be photoreal material work.

The pack remains `local_draft` until it has been examined in a real scene at
both close tabletop and zoomed-out map ranges. See `resource-pack.json` for the
complete lineage, tags, source paths, and non-assumed technical behavior.
